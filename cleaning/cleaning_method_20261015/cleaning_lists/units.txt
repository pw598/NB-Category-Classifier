# units.txt: how unit terms are standardised (steps 7 and 8 of 01_clean_data).
#
# One unit per line:      ABBREVIATION = form, form, form
#
#   ABBREVIATION  the abbreviated, singular form that every listed form is replaced by.
#                 It is recognised itself as well, so "10 MM" is glued to "10MM".
#   form          a full name, plural, spelling variant or other abbreviation.
#                 Forms may contain spaces ("CUBIC FEET") or punctuation ('"', "I.D.").
#   ~form         replaced only when it directly follows a number, glued or after a space
#                 ("10 FOOT" -> "10 FT"), never on its own. Use this for forms that are also
#                 ordinary words ("FOOT", "CASE", "DRIVE") or single characters.
#                 Forms without "~" are replaced wherever they appear as whole words.
#                 An abbreviation is only ever glued to a number, so it needs no "~".
#
#   A line starting with ">" is a prefix unit: it is glued to a number that FOLLOWS it
#   ("GRADE 8" -> "GR8"), unless a number comes before it ("8 GRADE" -> "8GR").
#
# Lines starting with "#" are comments. Case does not matter.
# Abbreviations are written without spaces ("CUFT", not "CU FT") so that each stays one word.
